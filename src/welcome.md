# 把想法，写成下一步。

一个安静的写作空间，留给值得记录的事。

欢迎来到 **页核 · PAGECORE**。这里可以阅读、编辑和保存 Markdown 文件。直接在这段文字中点击，就可以开始写作。

## 01 / 自然地写作

直接在排版后的正文中编辑。输入 `#` 后按空格创建标题，输入 `/` 打开插入菜单，选中文字调整格式。

> 保持专注，让工具退后一步。按 **F8**，只留下你和文字。

## 02 / 组织你的内容

- [x] 用标题把想法分成章节
- [x] 用左侧大纲快速跳转
- [ ] 写下今天最重要的一件事

| 模式 | 适合做什么 |
| :--- | :--- |
| 写作 | 直接在排版后的正文中编辑 |
| 分栏 | 一边修改源码，一边看效果 |
| 源码 | 精细调整 Markdown 原文 |
| 阅读 | 专心阅读完整文档 |

## 03 / 留下可复用的记录

打开本机的 `.md` 文件，按 **Ctrl + S** 保存。还可以插入图片、编辑表格、书写代码和数学公式。

```javascript
const nextStep = "从一行文字开始";
console.log(nextStep);
```
