# 页核 · PAGECORE v0.2.0

本次预览版主要整理代码结构和开发规范，继续提供本地 Markdown 写作、源码、分栏和阅读模式。

## 更新内容

- 将前端宿主通信、外观设置、快捷键、源码编辑器、图标及窗口控制拆分为独立模块。
- 将 Windows 程序启动、窗体状态、WebView2 集成、消息处理和文件对话框按职责分离。
- 统一 JavaScript、CSS、HTML、C# 和 PowerShell 格式，新增自动格式检查、静态检查和开发指南。
- 补充宿主通信、旧偏好兼容、版本一致性及浏览器交互回归测试，接入 GitHub Actions。
- 整理构建与第三方许可收集逻辑，构建错误会明确报告。
- 项目介绍直接描述页核自身的功能。

## 下载和升级

下载 `PageCore-v0.2.0-windows-x64.zip`，完整解压后运行 `启动页核.cmd`，需要 Windows x64、.NET Framework 4.8 和 WebView2 Runtime。`SHA256SUMS.txt` 可用于校验下载文件。

升级前先保存文档并关闭旧版。推荐解压到新目录；如需保留最近文件、外观和快捷键设置，在旧版关闭后，将旧目录中的 `.runtime` 文件夹复制到新版同级目录。不要在两个版本间同时共用这个文件夹。

本版仍为预览版：单文档窗口，不含多标签、云同步及 PDF/Word 导出。即时排版可能规范化 Markdown 写法；需要保留原文格式时请使用源码模式。
