# 页核 · PAGECORE v0.1.0

面向 Windows 的本地 Markdown 编辑器。把即时排版、源码和文件操作放在简洁的工业风写作空间里。

## 下载与启动

下载 **PageCore-v0.1.0-windows-x64.zip**，解压整个目录后双击 **启动页核.cmd**。请下载 Assets 中的应用包，Source code 仅包含源码。

需要 Windows x64、.NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。前端依赖已离线打包，不需要 Node.js 或本地服务器。此包为便携预览版，可执行文件尚未代码签名。

## 本版功能

- 写作、分栏、源码、阅读四种视图。
- 本地文件、大纲、最近文件、查找替换与 HTML 导出。
- 表格、任务列表、代码、图片和数学公式。
- 无边框界面、明暗主题、字号/行距设置与专注模式。
- 9 项自定义快捷键，录入冲突提示、即时保存与恢复默认。
- 编码/换行符保留、原子保存、备份、外部修改检测及恢复草稿。

## 使用前了解

目前仅支持单文档，不提供多标签、文件夹树、云同步、PDF/Word 导出与自动升级。即时排版可能规范化 Markdown 写法；对原文格式敏感时请用源码模式。单文档上限 10 MB，单张内嵌图片上限 4 MB。

配置、恢复草稿和备份在解压目录的 `.runtime/`。升级时退出应用并保留该目录；恢复草稿不是保存文件的替代品。

## 校验

同页的 **SHA256SUMS.txt** 包含应用压缩包的 SHA-256。可用 PowerShell `Get-FileHash .\PageCore-v0.1.0-windows-x64.zip -Algorithm SHA256` 与之核对。
