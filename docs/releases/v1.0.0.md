# 页核 · PAGECORE v1.0.0

页核首个 Windows x64 正式版，加入应用内自动升级，并重新整理整体界面。

## 本次更新

- 关于与更新：默认启动时检查正式版本，可关闭；支持手动检查、下载、SHA-256 完整性校验、安装并重启。
- 升级前检查未保存文档，取消关闭则不安装；保留设置、草稿和会话，替换程序失败时尝试恢复旧文件。
- 顶部整合为应用栏、文档标签和编辑工具，导出集中到右上角，保存状态移入底栏。
- 侧栏可折叠并记住宽窗口状态，窄窗口使用可关闭浮层；适配明暗主题与键盘操作。
- 包含多标签、文件夹工作区、全文搜索、会话恢复、图片粘贴拖入、PDF / Word / HTML 导出等现有功能。

## 下载与升级

下载 `PageCore-v1.0.0-windows-x64.zip`，完整解压到可写目录，运行 `启动页核.cmd`。`SHA256SUMS.txt` 提供校验值。

需要 Windows x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。当前为未签名的便携版。

旧版用户需手动升级到 1.0.0：先保存文档并关闭旧版，解压新版到新目录；如需迁移设置和会话，在旧版退出后复制其 `.runtime` 文件夹到新版目录。此后可从“设置 → 关于与更新”进行应用内升级。

自动升级只使用本仓库的正式 Release，不安装预发布版本。联网失败不影响离线编辑；缓存与旧程序备份位于 `.runtime/updates`。升级过程中请勿断电，用户文档请放在程序资源目录之外。
