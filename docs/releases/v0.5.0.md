# 页核 · PAGECORE v0.5.0

本次预览版加入文件夹工作区、全文搜索和会话恢复，并改进图片插入与弹窗体验。

## 新增与改进

- **文件夹工作区**：记住上次打开的目录，按需展开文件树，新建文档与文件夹、重命名文档、刷新；重复打开复用标签。
- **全文搜索**：按 `Ctrl+Shift+F` 搜索工作区 Markdown 与文本文件，支持区分大小写、匹配高亮、行号跳转与取消搜索；已打开文件的未保存内容也参与检索。
- **会话恢复**：重启后恢复标签顺序、当前文档、编辑模式、源码选区和阅读位置；重新读取磁盘文件，缺失文件跳过并提示。
- **图片粘贴与拖入**：支持 PNG、JPEG、GIF 和 WebP，以及图片按钮多选。图片保存到文档旁的资源文件夹，以相对路径引用；新文档先保存后插图。
- **统一弹窗**：文件选择、保存确认、覆盖提示与文件夹操作使用页核的明暗主题，调整标题、输入框、列表行距和按钮比例，支持键盘操作。
- **项目结构**：脚本、配置与发布文档分别归入 `scripts/`、`.config/` 和 `docs/`，简化根目录，更新构建与验证流程。

## 下载和升级

下载 `PageCore-v0.5.0-windows-x64.zip`，完整解压后运行 `启动页核.cmd`。`SHA256SUMS.txt` 提供 SHA-256 校验值。

需要 Windows x64、.NET Framework 4.8 和 WebView2 Runtime；PDF 页眉、页脚和页码需要 WebView2 131 或更新版本。

升级前保存文档并关闭旧版。建议解压到新目录；如需迁移设置、最近文件、工作区、会话和恢复草稿，可在旧版关闭后将其 `.runtime` 文件夹复制到新版同级目录。不要让两个版本同时共用该目录。

## 使用说明

- 正常关闭仍会询问是否保存，选择放弃的修改不会自动恢复；异常退出的内容通过“恢复草稿”找回。跨次启动不保留撤销记录。
- 全文搜索为单行文字匹配，默认跳过隐藏目录、依赖目录和超过 2 MB 的磁盘文件；最多显示 300 个结果，达到扫描上限时会提示。
- 单张图片不超过 10 MB；移动文档或另存为到其他目录时，需要一并复制对应资源文件夹。
- 当前为未签名的 Windows x64 便携预览版，尚不提供云同步或自动升级。
