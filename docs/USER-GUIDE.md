# 页核使用指南

## 开始写作

解压完整发布包后双击 `启动页核.cmd`。左侧可新建、打开文件，或者把 Markdown 文件拖到启动脚本上。右上角保存按钮和 Ctrl+S 都会保存当前文件；首次保存会让你选择位置。Ctrl+Shift+S 用于另存为。

打开、保存、导出以及选择文件夹时，会显示页核风格的文件窗口。可以从左侧选择常用位置和磁盘，双击文件夹进入，点击 ↑ 返回上一级，也可在地址栏输入本地路径后按 Enter。选择文件或输入文件名后按「打开」或「保存」；Esc 或「取消」会返回编辑器。覆盖现有文件和关闭未保存文档前，页核会显示确认提示。

## 文件夹工作区

在左侧点击「打开文件夹」，选择存放文档的本地目录。页核会记住该目录，下次启动时恢复工作区。工作区仅显示文件夹和 `.md`、`.markdown`、`.txt` 文件；隐藏项、依赖目录以及目录联接、符号链接不展开。

「文件」「文档大纲」「最近文件」可随时切换。点击文件夹展开或收起，点击文档在标签页中打开；已打开的文档会切换到原标签，保留未保存的修改与撤销记录。当前文档在文件树中有标记。

选中文件夹后，使用文件树上方的 ＋ 或文件夹按钮创建文档或子文件夹；选中文档时，在它所在的目录创建。点击工作区名称可选择根目录。新文档未填写扩展名时自动添加 `.md`，创建后直接打开。同名文件和文件夹不会被覆盖。

选中文档后，点击重命名按钮或按 F2 修改文件名。重命名会同时更新磁盘文件和打开的标签，保留未保存内容、编码及撤销记录。当前仅提供文档重命名。

文件树获得焦点后，可用上下方向键、Home、End 移动，左右方向键展开、收起或回到父级，Enter 打开文档。在其他软件中增删文件后，可点击刷新；重新回到页核窗口时也会刷新可见工作区。关闭或更换工作区会保留已打开的文档。工作区不会复制、搬移目录中的现有文件。

## 多标签页

新建、打开和最近文件会在新标签中打开文档；重复打开同一路径会切换到已有标签，保留未保存的修改。每个标签独立保留正文、撤销记录、选区、视图模式、滚动位置和保存状态。标签上的小圆点表示尚未保存，悬停文件名可查看完整路径。

点击标签切换，点击右侧 × 或按 Ctrl+W 关闭；Ctrl+N 新建，Ctrl+Tab / Ctrl+Shift+Tab 循环切换。标签获得焦点后也可用左右方向键、Home、End 导航，鼠标中键可关闭标签。标签过多时横向滚动，关闭最后一页会新建一个空白标签。这三项标签快捷键可在设置中修改。

保存、另存为、查找及导出只作用于当前标签。关闭有修改的标签时，可选择保存、放弃或取消；退出应用会逐一检查所有标签。不能另存为另一已打开标签所对应的文件，避免覆盖另一份编辑内容。异常退出后可同时恢复多份未保存草稿；正常退出后再次启动可恢复标签和阅读位置；放弃的修改不会恢复，撤销记录不跨次启动保留。

## 四种视图

- **写作**：在正文中直接编辑。输入 `#` 后按空格生成标题，输入 `/` 打开插入菜单；选中文字后使用浮动工具或顶部格式按钮。
- **分栏**：左侧源码，右侧实时预览。
- **源码**：直接编辑 Markdown；查找与替换在这里使用。需要保留原始语法细节时优先使用此模式。
- **阅读**：排版后的只读视图。

左侧大纲按标题生成，点击可跳到相应段落。

## 图片粘贴与拖入

在写作或源码编辑区粘贴截图、拖入图片，或者点击工具栏的图片按钮选择一张或多张图片。支持 PNG、JPEG、GIF 和 WebP，单张图片不超过 10 MB。图片插入到当前光标或拖放位置，文档使用相对路径引用。

桌面版会将图片保存到文档旁边的同名资源文件夹，例如 `笔记.md` 的图片放在 `笔记_assets/`。未保存的新文档会先要求选择保存位置；取消时不会插入图片。重复插入不会覆盖已有图片，插入的引用仍需保存文档后才会写入 Markdown 文件。

移动文档或将其另存到其他目录时，请将 Markdown 引用的资源文件夹一并复制过去，并保持相对位置。浏览器和其他嵌入宿主无法直接写入本地文件夹，图片会以内嵌数据写入文档；这时文档本身也需要满足大小限制。

## 外观和快捷键

点击顶栏设置图标，或按默认 Ctrl+,。外观页可选择浅色/深色、80%–150% 字号和三档正文行距。更改即时生效并保存；底部状态栏的字号按钮与设置同步。

快捷键页支持新建、打开、保存、另存为、关闭标签、上一个/下一个标签、查找、工作区全文搜索、加粗、斜体、专注、打开设置这 13 项操作：

1. 点击操作右侧的当前组合键。
2. 按下新的组合键；可以使用 Ctrl + 字母/数字/逗号/Tab，可加 Shift，或 F2/F8/F9。
3. 无冲突时自动保存。重复分配、系统和常用编辑快捷键会提示，请另选组合键。

Esc 或离开录入按钮可取消。改键后工具提示和帮助页同步更新，原组合键不再执行该操作。「恢复默认快捷键」只恢复快捷键，不影响外观。外观页的「恢复默认」也不改变快捷键。

## 文件与恢复

保存前会检查文件是否被其他程序修改；有冲突时不会直接覆盖。读取过的文件会尽量保留原编码和换行符，未编辑时保存不改写原字节。

异常退出后如果存在草稿，下次启动会提示恢复。恢复得到未命名副本，请检查后另存为。`.runtime/backups/` 中保留保存前的文件副本，需自行整理。

便携版需要放在你有写入权限的目录。升级时先退出程序、备份重要文档，再替换程序文件，保留 `.runtime/`。不要只复制 EXE，`bin/` 与 `dist/` 都是运行必需内容。

## 导出和限制

「导出 PDF」先打开排版设置，再选择保存位置。支持 A4、A5、Letter，横向/纵向，四边独立页边距（5–40 mm），正文字体、字号（8–24 pt）、行距、自定义页眉/页脚和“第 X / N 页”页码。默认 A4 纵向、11 pt；成功导出后记住设置，取消不会覆盖上次设置，可随时恢复默认。页眉位于左上，页脚位于左下，页码位于右下；启用时对应上下边距至少 12 mm。页眉页脚最多 60 个字符，超出可用宽度会截断。页眉页脚和页码需要 WebView2 131 或更新版本。

「导出 Word」生成可编辑的 `.docx`，无需安装 Microsoft Word 即可导出。支持标题、加粗、斜体、删除线、链接、编号/无序/任务列表、表格、代码、引用、图片和常见数学公式。使用 A4、20 mm 页边距，正文 11 pt；PDF 设置仅应用于 PDF。常见公式转换为 Word 原生公式，无法转换的公式保留 LaTeX 原文并提示检查。任务框作为符号保留。图片内嵌为 PNG，GIF 保留静态画面；外部图片需允许跨域读取，失败时可下载到文档目录再导出。复杂 HTML 布局和合并单元格不保证完全还原。

「导出 HTML」导出当前文档排版。三种导出都包含当前尚未保存的修改，不改变 Markdown 的保存状态，也不会导出工具栏和侧栏。文档目录及子目录内支持格式的相对图片会内嵌。PDF 和 Word 导出需要桌面版；图片无法读取时会报错，取消或生成失败不会覆盖已有目标文件。

单文档最大 10 MB，单张插入图片最大 10 MB。大文档、YAML 头部或复杂 HTML 可能自动使用源码模式。直接写作会进行 Markdown 解析和序列化，不保证所有自定义语法原样往返。

## 工作区全文搜索

先打开文件夹工作区，再点击左侧“搜索”或按 `Ctrl+Shift+F`（可在快捷键设置中修改）。输入关键词后自动搜索，也可以按 Enter。搜索按原文匹配，支持区分大小写，不解释正则表达式。

结果按文件排列，显示行号和高亮片段；点击结果切换到源码模式并选中匹配位置，已经打开的文件复用标签，不丢弃未保存修改或撤销记录。搜索包含工作区内已打开文件的未保存内容；没有保存路径的新文档不属于文件夹搜索范围。文档内容变化后可以再次搜索刷新结果。

搜索在后台进行，可以点击“停止”。更换关键词、关闭或切换工作区会取消旧搜索。跳过隐藏/系统文件、符号链接、目录联接、`.git`、`.runtime`、`node_modules`、`.pnpm-store` 以及不可读取的项目；磁盘文件超过 2 MB 时跳过。单次最多返回 300 处匹配，扫描 2000 个文档、10000 个目录项目、约 30 MB 文本或运行 10 秒；达到上限时会明确提示，可以选择更具体的工作区。

## 会话恢复

桌面版自动记住打开的文件、标签顺序、活动标签、写作/源码/分栏/阅读模式、源码选区和各视图的滚动位置。正常退出再启动会重新读取磁盘文件并恢复这些状态；不恢复跨重启的撤销历史。外部修改以磁盘内容为准，文件被移动或删除时跳过并提示，其余标签继续恢复。一次最多恢复 100 个标签及约 10 MB 文档，超出部分请手动打开。

会话记录位于 `.runtime/session.json`，草稿记录独立存放。关闭时仍会询问是否保存：选择“不保存”的内容不会因会话恢复而重新出现。异常退出的未保存修改仍通过顶部“恢复草稿”入口恢复为独立草稿，避免覆盖磁盘文件；尚未处理的恢复草稿不会被正常退出清除。恢复不是自动保存，请继续使用 Ctrl+S 保存重要修改。
