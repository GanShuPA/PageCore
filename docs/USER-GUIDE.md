# 页核使用指南

## 开始写作

解压完整发布包后双击 `启动页核.cmd`。左侧可新建、打开文件，或者把 Markdown 文件拖到启动脚本上。右上角保存按钮和 Ctrl+S 都会保存当前文件；首次保存会让你选择位置。Ctrl+Shift+S 用于另存为。

## 四种视图

- **写作**：在正文中直接编辑。输入 `#` 后按空格生成标题，输入 `/` 打开插入菜单；选中文字后使用浮动工具或顶部格式按钮。
- **分栏**：左侧源码，右侧实时预览。
- **源码**：直接编辑 Markdown；查找与替换在这里使用。需要保留原始语法细节时优先使用此模式。
- **阅读**：排版后的只读视图。

左侧大纲按标题生成，点击可跳到相应段落。图片按钮支持 PNG、JPEG、GIF 和 WebP；本机插入图片会以内嵌数据保存到 Markdown。

## 外观和快捷键

点击顶栏设置图标，或按默认 Ctrl+,。外观页可选择浅色/深色、80%–150% 字号和三档正文行距。更改即时生效并保存；底部状态栏的字号按钮与设置同步。

快捷键页支持新建、打开、保存、另存为、查找、加粗、斜体、专注、打开设置这 9 项操作：

1. 点击操作右侧的当前组合键。
2. 按下新的组合键；可以使用 Ctrl + 字母/数字/逗号，可加 Shift，或 F2/F8/F9。
3. 无冲突时自动保存。重复分配、系统和常用编辑快捷键会提示，请另选组合键。

Esc 或离开录入按钮可取消。改键后工具提示和帮助页同步更新，原组合键不再执行该操作。「恢复默认快捷键」只恢复快捷键，不影响外观。外观页的「恢复默认」也不改变快捷键。

## 文件与恢复

保存前会检查文件是否被其他程序修改；有冲突时不会直接覆盖。读取过的文件会尽量保留原编码和换行符，未编辑时保存不改写原字节。

异常退出后如果存在草稿，下次启动会提示恢复。恢复得到未命名副本，请检查后另存为。`.runtime/backups/` 中保留保存前的文件副本，需自行整理。

便携版需要放在你有写入权限的目录。升级时先退出程序、备份重要文档，再替换程序文件，保留 `.runtime/`。不要只复制 EXE，`bin/` 与 `dist/` 都是运行必需内容。

## 导出和限制

「导出 PDF」先打开排版设置，再选择保存位置。支持 A4、A5、Letter，横向/纵向，四边独立页边距（5–40 mm），正文字体、字号（8–24 pt）、行距、自定义页眉/页脚和“第 X / N 页”页码。默认 A4 纵向、11 pt；成功导出后记住设置，取消不会覆盖上次设置，可随时恢复默认。页眉位于左上，页脚位于左下，页码位于右下；启用时对应上下边距至少 12 mm。页眉页脚最多 60 个字符，超出可用宽度会截断。页眉页脚和页码需要 WebView2 131 或更新版本。

「导出 Word」生成可编辑的 `.docx`，无需安装 Microsoft Word 即可导出。支持标题、加粗、斜体、删除线、链接、编号/无序/任务列表、表格、代码、引用、图片和常见数学公式。使用 A4、20 mm 页边距，正文 11 pt；PDF 设置仅应用于 PDF。常见公式转换为 Word 原生公式，无法转换的公式保留 LaTeX 原文并提示检查。任务框作为符号保留。图片内嵌为 PNG，GIF 保留静态画面；外部图片需允许跨域读取，失败时可下载到文档目录再导出。复杂 HTML 布局和合并单元格不保证完全还原。

「导出 HTML」导出当前文档排版。三种导出都包含当前尚未保存的修改，不改变 Markdown 的保存状态，也不会导出工具栏和侧栏。文档目录及子目录内支持格式的相对图片会内嵌。PDF 和 Word 导出需要桌面版；图片无法读取时会报错，取消或生成失败不会覆盖已有目标文件。暂不支持多标签与文件夹树。

单文档最大 10 MB，单张内嵌图片最大 4 MB。大文档、YAML 头部或复杂 HTML 可能自动使用源码模式。直接写作会进行 Markdown 解析和序列化，不保证所有自定义语法原样往返。
