# 页核 · PAGECORE v0.3.0

本次预览版新增 PDF 排版设置和可编辑 Word 导出，并修复任务列表对齐及窗口还原时的界面裁切。

## PDF 导出

点击工具栏「导出 PDF」，设置排版后选择保存位置。

- 支持 A4、A5、Letter，纵向与横向，以及四边独立页边距。
- 可选择字体、字号、行距，自定义页眉、页脚，并显示“第 X / N 页”页码。
- 成功导出后记住设置，支持恢复默认；取消不会覆盖上次设置。
- 支持中文、图片、数学公式、跨页表格和长代码自动换行。

## Word 导出

点击「导出 Word」生成可编辑 `.docx`，导出过程无需安装 Office。

- 保留标题、加粗、斜体、删除线、链接、列表、表格、引用、代码和图片。
- 常见公式转换为 Word 原生公式；不支持的公式保留 LaTeX 原文并提示检查。
- 本地图片内嵌到文件中，任务框保留为符号，GIF 使用静态画面。

两种导出均包含当前尚未保存的修改，不改变原 Markdown 的保存状态。取消或生成失败不会覆盖已有目标文件。

## 修复与验证

- 修复复选框与任务文字不在同一行的问题。
- 修复最大化还原到窗口模式时，窗口内容异常裁切的问题。
- 24 项单元测试、6 项浏览器交互测试，以及原生文件会话与 PDF 参数校验通过。
- 本机实际验证三种纸张的横竖 PDF 排版，并用 Microsoft Word 打开并检查包含 58 行表格、图片和原生公式的 6 页导出样例。

## 下载和升级

下载 `PageCore-v0.3.0-windows-x64.zip`，完整解压后运行 `启动页核.cmd`。`SHA256SUMS.txt` 提供 SHA-256 校验值。

需要 Windows x64、.NET Framework 4.8 和 WebView2 Runtime；PDF 页眉、页脚和页码需要 WebView2 131 或更新版本。

升级前保存文档并关闭旧版。建议解压到新目录；要迁移最近文件、外观和快捷键设置，可在旧版关闭后将其 `.runtime` 文件夹复制到新版同级目录。不要让两个版本同时共用这个文件夹。

仍为单文档预览版，暂不包含多标签、文件夹树、云同步和自动升级。Word 复杂 HTML 布局、合并单元格及部分公式可能无法完全还原；网络图片须可访问并允许跨域读取。详细说明见使用指南。
