# 页核 · PAGECORE v0.4.0

本次预览版加入多标签页，可以在同一个窗口中编辑多篇 Markdown 文档。

## 多标签页

- 新建、打开和最近文件会打开新标签；重复打开同一文件会切换到已有标签，保留未保存的修改。
- 各标签独立保留内容、撤销记录、视图、选区、滚动位置和保存状态；标签上的圆点表示未保存。
- 默认使用 Ctrl+N 新建、Ctrl+W 关闭、Ctrl+Tab 和 Ctrl+Shift+Tab 切换标签，这些快捷键可在设置中修改。标签过多时可横向滚动，也支持鼠标中键关闭。
- 保存、另存为及 HTML、PDF、Word 导出作用于当前标签。另存为时会阻止覆盖另一个已打开的文件。
- 关闭标签会检查该文档的未保存更改；退出程序时逐一检查所有标签。异常退出后可同时恢复多份未保存草稿。
- 本地图片按各自文档目录读取，避免不同文件夹中同名图片混用。

## 下载和升级

下载 `PageCore-v0.4.0-windows-x64.zip`，完整解压后运行 `启动页核.cmd`。`SHA256SUMS.txt` 提供 SHA-256 校验值。

需要 Windows x64、.NET Framework 4.8 和 WebView2 Runtime；PDF 页眉、页脚和页码需要 WebView2 131 或更新版本。

升级前保存文档并关闭旧版。建议解压到新目录；要迁移最近文件、外观和快捷键设置，可在旧版关闭后将其 `.runtime` 文件夹复制到新版同级目录。不要让两个版本同时共用这个文件夹。

正常退出后暂不自动重新打开全部标签；文件夹树、云同步和自动升级尚未提供。详细说明见使用指南。
