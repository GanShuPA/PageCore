# 版本记录

## v1.0.0 · 2026-10-29

- 首个正式版，新增关于与更新：自动检查正式版本、下载校验、安装重启及失败回滚；保留文档、设置与会话。

- 重整应用栏、文档标签与编辑工具，集中导出菜单，将保存状态移入底栏，扩大正文空间。
- 侧栏支持收起与状态记忆，小窗口使用可关闭的浮层，保留文件、大纲、最近和搜索入口。
- 补齐导出菜单的键盘导航、焦点返回以及不同窗口尺寸下的布局回归测试。

## v0.5.0 · 2026-10-28

- 新增工作区全文搜索：后台检索、区分大小写、匹配高亮、行号跳转、取消搜索，并包含已打开文件的未保存内容。
- 新增会话恢复：记住标签顺序、活动文档、编辑模式、源码选区及各视图阅读位置；缺失文件跳过并提示，正常关闭不恢复已放弃的修改。
- 调整弹窗比例：文件窗口采用更紧凑的尺寸和舒展的列表行距，统一输入框、按钮、标题层级；补齐深色控件，长提示自适应高度，小窗口内支持滚动。
- 将文件和文件夹选择、保存确认及覆盖提示统一为页核样式，支持明暗主题和键盘操作。
- 增加图片粘贴、多图拖入及图片按钮多选；桌面版以相对路径引用文档旁的资源文件夹。
- 新文档插图前先选择保存位置，校验图片格式和大小，并避免覆盖已有图片。
- 新增文件夹工作区：记住本地目录、按需展开文件树、新建文档与文件夹、重命名文档、手动及窗口激活刷新。
- 工作区接入多标签页；重复打开复用标签，重命名保留未保存正文、撤销记录和原始编码。
- 将构建、检查与发布脚本归入 scripts/，工具配置归入 .config/，HTML 入口归入 src/。
- 将版本记录和历史发布说明集中到 docs/，安装包输出到 release/packages/，第三方许可输出到 dist/licenses/。
- 同步更新构建、测试、CI 和文档引用，发布包排除本地演示材料。

## v0.4.0 · 2026-10-27

- 新增多标签页：独立编辑状态、撤销记录、视图、选区和滚动位置，标签显示未保存标记。
- 新建/打开保留已有文档，重复打开同一路径切换到已有标签；保存与导出只作用于当前标签。
- 支持关闭标签、循环切换的可自定义快捷键，以及关闭和退出时的逐文档保存确认。
- 多份未保存草稿可同时恢复，本地图片按标签隔离路径，防止不同文件夹的同名图片混用。

## v0.3.0 · 2026-10-27

- 新增 PDF 导出与排版设置：纸张、横竖方向、页边距、字体、字号、行距、页眉、页脚和页码。
- PDF 设置在成功导出后保存在本机，支持取消及恢复默认。
- 新增可编辑 Word（.docx）导出，支持标题、文字格式、列表、表格、引用、代码、图片和常见原生公式。
- 导出包含当前未保存的修改，不改变 Markdown 的保存状态；失败不覆盖已有目标文件。
- 修复任务列表复选框与文字错位，以及最大化切回窗口模式时的界面裁切。
- 补充导出内容、设置持久化、取消和失败路径的回归测试，并更新使用与嵌入文档。

## v0.2.0 · 2026-10-26

- 按职责拆分前端和 Windows 宿主，统一代码格式。
- 加入 Prettier、ESLint、CSharpier 和 PowerShell 规范检查。
- 补充通信、偏好、版本与浏览器交互回归测试，并接入 CI。
- 更新开发规范、构建流程及发布说明；兼容现有设置和嵌入接口。

## v0.1.0 — 2026-10-25

首个 Windows x64 公开预览版。

- 即时排版、分栏、源码与阅读四种视图。
- 本地文件打开/保存、最近文件、大纲、查找替换和 HTML 导出。
- 表格、任务、代码、图片与 KaTeX 数学公式。
- 无边框工业风界面、浅色图标、明暗主题、字号、行距和专注模式。
- 自定义 9 项快捷键，冲突检查、即时保存、提示同步与恢复默认。
- 多编码与换行符保留、原子保存、备份、外部修改检测和草稿恢复。
- 便携发布包、SHA-256 校验、自动构建与发布验证。

此版尚未提供多标签、文件夹树、PDF/Word 导出、云同步与自动升级。
